# WizNerdZ Pixel Paragon Color, Weight, and Rule Pack

This pack contains the starter production system for a 10,000 piece pixel NFT collection.

## Locked collection setup

- Collection: WizNerdZ Pixel Paragon
- Working canvas: 64x64
- Final export: 4096x4096
- Scaling: nearest neighbor only
- Orange is most rare
- Green is second rarest
- Blue is third rarest
- Purple is most common

## Files

- `palette.json`: color families, hex values, roles, variant weights
- `weights.json`: category trait weights
- `rules.json`: visual rules, incompatibility rules, synergy bonuses
- `generator_logic.md`: generator flow and rarity scoring logic

## Main rarity order

1. Orange
2. Green
3. Blue
4. Purple

## Suggested family weights

Orange: 3  
Green: 8  
Blue: 18  
Purple: 35

This gives orange enough rarity to matter without making the collection feel empty of orange.
