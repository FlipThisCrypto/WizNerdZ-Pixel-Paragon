# Contributing to WizNerdZ Pixel Paragon

## Community PFP nominations (primary)

Until **midnight July 31, 2026 (US Eastern)**:

1. Use the form at https://flipthiscrypto.github.io/WizNerdZ-Pixel-Paragon/#nominate  
   **or** open a GitHub Issue titled `[PFP Nomination] handle (platform)`.
2. Include nominee handle, platform, optional `xch` wallet, PFP URL, and notes.
3. Fiend Studios will review after the deadline and produce 1:1 WizNerdZ-themed art.

Do not open PRs that replace generative slots without coordination.

## Code / site PRs

- Live site root is `docs/` (GitHub Pages).
- Public config only in `docs/js/config.js` — **never** commit private keys.
- Keep the chrome / wet-paint visual language (blacks, silvers, blues, light-green highlights).
- Prefer small, reviewable PRs with a clear user benefit.

## Reporting bugs

- Site/mint UX: GitHub Issues with steps to reproduce.
- Security: see [SECURITY.md](SECURITY.md).

## Operator tools

- `docs/operator.html` — day-to-day links
- `docs/OPS.md` — incident runbook
