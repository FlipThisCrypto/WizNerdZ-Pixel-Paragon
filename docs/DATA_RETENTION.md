# Data retention

| Data | Location | Retention |
|------|----------|-----------|
| Art + metadata | GitHub Pages / git | Indefinite while collection live |
| Nominations | GitHub Issues | Keep history for provenance |
| Local nominations | Browser localStorage | Max 50; user-clearable |
| Telemetry / funnel | Browser localStorage | Ring buffer; not uploaded |
| WC sessions | WalletConnect storage | User disconnect |

## Deletion

Users clear site data in browser settings.
Prefer close+label on GitHub issues over hard delete for audit.
