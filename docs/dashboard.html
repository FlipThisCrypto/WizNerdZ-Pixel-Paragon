Project direction

WizNerdZ Pixel Paragon is an 8,888-piece generative pixel-art NFT collection for the Chia blockchain (CHIP-0007), published by Fiend Studios. Art is assembled from curated 32×32→640×640 layers with class-matched robes/hats, light backgrounds for black-outline POP, and optional rare extras (staff / spell / familiar).

North star / One Thing

  • NOW: Sealed-box mint is live end-to-end — dispense → WalletConnect takeOffer → chain-settled delivery → on-page reveal. First real sale fulfilled (Hyperhex 1/1, blind single).
  • Landing live: countdown, nominate→GitHub Issues, Sage WC, chrome UI, token viewer, rarity table
  • Metadata: absolute Pages image URLs on all 8,888 CHIP-0007 files
  • Splits 40% dev / 40% wizards / 20% Bepe.Love · royalties 10% · wallet configured
  • Full drop pending: branded box inventory + real tier pricing, then offers load in bulk

Non-goals (for now)

  • No custodial mint keys in the browser or repo
  • No custodial signing in serverless — delivery signing stays operator-side until custody is decided
  • No reintroducing the old 64×64 rulepack pipeline (archived locally)

When a box sells

  • 1
    Detection is automatic
    The scheduled watcher marks the box SOLD and retires its offer within ~5 minutes. Check the Mint API row above — heartbeat age is the liveness signal.
  • 2
    Delivery is operator-side (by design)
    Resolve the settlement recipient, deliver the committed WizNerdZ, publish the status: mint_system tooling — settlement_watcher · chia_fulfillment deliver · push_status_to_site.
  • 3
    Before any real drop
    npm run preflight must be clean (also runs every 6h via Actions and on demand), inventory loaded at real prices, and the delivery runbook open.

Mint direction (sealed boxes on Chia)

Buyers take an offer for a generic sealed box (offers are transparent — a real WizNerd would be snipeable). Contents were Merkle-committed before sale; delivery follows the settlement transaction's recipient, never later possession. Full design: mint economics · the commitment.
